# Ultra Yavaş Toplama Makinesi

## Giriş: İnsanlığın En Büyük Sorunu Çözüldü

Sevgili kullanıcılar, bugün tarih yazıyoruz. Modern dünyanın en büyük belası olan "acelecilik" hastalığına karşı nihai silahımız: **Ultra Yavaş Toplama Makinesi**.

Bu proje, sadece iki sayıyı toplamakla kalmaz; sizi sabırlı olmaya, hayatın tadını çıkarmaya, çay demlenirken düşünmeye zorlar. Bilimsel araştırmalar (ki yok) göstermiştir ki, bu makineyi kullananlar %347 daha mutlu, %999 daha az stresli olur.

## Nasıl Çalışır?

1. Python 3 ile çalıştırın: `python ultra_yavas_toplama.py`
2. İki küçük sayı girin (büyük girerseniz makine sizi yargılar).
3. Bekleyin. Çok bekleyin. Çay için. Kitap okuyun. Evreni sorgulayın.
4. Sonucu alın ve şaşırın: Evet, 2+2 gerçekten 4.

## Özellikler

- Rastgele felsefi sorular
- Gerçek zamanlı yavaşlık (saniyelerce)
- Gizli easter egg'ler (bulmaya çalışma)
